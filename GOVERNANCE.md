# Governance

This repository is maintained as a small public process toolkit.

## Decision Model

Maintainers decide:

- Project scope and positioning.
- License and public safety boundaries.
- Which process claims are acceptable.
- Whether a contribution is clear enough for humans and agents.

Contributors may propose:

- New templates.
- Better skill contracts.
- Stronger validation.
- Examples and corrections.

## Review Standard

Changes should improve at least one of:

- Human readability.
- Agent operability.
- Public safety.
- Evidence quality.
- Adaptability.

Changes that add complexity must explain what risk or user pain the complexity
removes.
