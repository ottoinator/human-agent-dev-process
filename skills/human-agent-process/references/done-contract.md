# Done Contract Reference

Work is done when the relevant slice satisfies:

- Intent is clear or assumptions are explicit.
- Owner decisions are resolved.
- Scope and non-goals are clear.
- Implementation is complete and scoped.
- QA evidence matches the claims.
- Security/privacy review ran where relevant.
- Documentation changed where behavior changed.
- Runtime or artifact proof exists where claimed.
- Final report includes limits and remaining risks.

For AI-only work, mark missing human validation explicitly.
