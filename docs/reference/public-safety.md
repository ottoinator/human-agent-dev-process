# Public Safety

Public repositories need a stricter default than private workflows.

## Do Not Publish

- Secrets, tokens, credentials, cookies, private keys.
- `.env` files.
- Private logs, transcripts, screenshots, traces, or raw support data.
- Local machine paths or hostnames.
- Customer, employee, family, or personal raw data.
- Operational runbooks that reveal private infrastructure.

## Safe Pattern

Convert private workflow knowledge into:

- Abstract principles.
- Sanitized examples.
- Placeholder-based templates.
- Public-safe skill contracts.
- Evidence labels instead of private proof dumps.

## Review Checklist

- Are examples fictional or sanitized?
- Are all links intended to be public?
- Does any path reveal a private machine or network?
- Does any text imply validation that has not happened?
- Does any agent instruction grant broad permissions without approval rules?
