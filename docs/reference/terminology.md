# Terminology

## Agent

An AI system or coding assistant acting on a task with tools, context, and
instructions.

## Business Owner

The human decision-maker for goals, priorities, risk, scope, cost, and release.

## Gate

A decision point that checks whether work can safely proceed, needs revision, or
requires owner input.

## Evidence

An artifact that supports a claim: test result, health check, screenshot, log,
review, source comparison, or validation report.

## AI-Only Validation

Validation performed by automated tests, synthetic reviewers, simulations,
fixtures, or agent reviews. Useful, but not the same as real user, customer,
market, or expert validation.

## Done Contract

The conditions that must be satisfied before work is honestly complete.
