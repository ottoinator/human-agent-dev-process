# Repository Boundaries

The repository has four main content types.

## Normative Docs

Location: `docs/process/`

These files define the process. Keep them clear and stable.

## Reference Docs

Location: `docs/reference/`

These files explain terms, maintenance, validation, and supporting guidance.

## Templates

Location: `templates/`

These files are meant to be copied into other repositories and adapted. They may
contain placeholders and optional sections.

## Skills

Location: `skills/`

These files translate the process into agent-operational instructions. A skill
should have a clear trigger, operating rules, workflow, and output contract.

## Examples

Location: `examples/`

Examples are illustrative. They help users see the process in action, but they
are not the source of truth.
